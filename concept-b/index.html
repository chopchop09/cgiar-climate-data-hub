Ask what CGIAR is doing about climate

One question, answered three ways on this page: the evidence that already exists, the projects working on it, and a brief assembled from both. There is nowhere else to go, and nothing behind a second click.

For example

The bet this concept makes

That the three layers are a build sequence for us, not a structure for the visitor. Someone arriving with a question should not need to know that answering it involves a static collection, a query layer and a synthesis step. So all three sit on one page, all three react to the same query, and there is no navigation between them. The cost of the bet: the page is long, and a visitor who only wanted one link scrolls past two bands that were not for them. Compare against Concept A before deciding.

1

What already exists

Real search, small corpus. Plain keyword matching over the 44 items catalogued on this prototype, run in your browser. It does not reach CGSpace, Gardian, the Data Hub catalogue or any live source. Nothing you type is sent anywhere. The experts listed are the use-case champions already published on the current prototype, not a directory: the centre-by-centre list does not exist yet and no opt-out process has been agreed.
2

Who is working on it

The portfolio is eight use cases. Status, programme and champion are as recorded on the current prototype. Four of the eight are ideas rather than funded work, and two have no champion named. An empty result in this band is informative: it says nobody has picked the topic up.
3

Build a brief from it

No figures are populated, on purpose. The section structure and the named source layers are real, and they update with your query above. The numbers are not there because no country-level figures have been compiled, and filling them with plausible placeholders would make this impossible to review honestly. The programme publishes a count of priority countries, 20 Tier 1 and 6 Tier 2, but the names were not confirmed for this prototype.

Reading this as a work plan: the first three sections could be assembled from layers that already exist. The next two need work that has not been resourced. The last needs the expert directory, which does not exist.
