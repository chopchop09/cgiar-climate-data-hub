What is CGIAR doing on a topic, in a place?

One keyword field and three filters, run across all six collections at once. This is the layer the feedback described as sitting on top of the static content: it adds no new material, it only makes the material answerable.

Real search, small corpus. This searches the 44 items catalogued on this prototype by plain keyword matching in the browser. It does not reach CGSpace, Gardian, the Data Hub catalogue or any live source, so an empty result means the prototype has not catalogued it, not that CGIAR has not done it. No network calls are made and nothing you type is sent anywhere.
